# Kiwi Bird

<BiomeScreenshot id="kiwi_bird" name="Kiwi Bird" />

*A shy little forager that would rather dig for grubs in the dark than deal with the day.*

A passive bird. See [Creature Settings](../getting-started/configuration.md#creature-settings) and the [Content Settings](../getting-started/configuration.md#content-settings) to adjust its spawn weight or disable it.

| Stat | Value |
|---|---|
| Spawn biomes | Woodlands, Great Oak Lowlands, Deciduous Forest |
| Spawn weight | 25 (`kiwiSpawnWeight`) |
| Forage attempt interval | ~120 ticks (`kiwiForageAttemptInterval`) |
| Worm find chance | 33% (`kiwiWormFindChance`) |
| Egg interval | 10 to 20 minutes (`kiwiEggLayInterval`) |
| Meat drop | 1 Raw Kiwi Meat (`kiwiMeatDropCount`) |

- **Sleeps by day and is active at night.**
- **Digs itself a burrow** to sleep in nearby, and goes back to the same one each morning if it's still there.
- **Digs up worms at night**, dropping one every so often while it forages.
- **Tempted by Salal Berries or a Worm** - hold either to lead it around - and feeding it one lets it breed.
- **Lays Kiwi Eggs** every so often once it is an adult. A Kiwi Egg can be used in place of an egg in the [pie and pancake recipes](../items-and-food/food.md).
- **Drops Raw Kiwi Meat** when killed (plus the odd feather), and Cooked Kiwi Meat instead if it dies while burning. Looting adds extra meat.
